# Root 增强

有些事只有在手机真正的 root 身份下才能做：看 GPU 和显示相关的节点、读写其他应用的数据、改系统属性、把守护进程常驻。Root 增强让 DSH 在得到你的一次授权后，用 root 身份执行这些命令；PRoot 里看不到的路径，从这里能看到。

Root 增强只在本机引擎可用，需要手机已经 root（Magisk、KernelSU 或 APatch 均可），并且 root 管理器允许 DSH Go。

## 开启

<!-- nav: commonSettings,hubGroupCapabilities,phoneRootExecTitle -->
`设置 › 能力 › Root 增强`

1. 打开页面，确认状态里授权、连接都是未授权、未连接。
2. 点一次授权，阅读说明后点授权并连接。root 管理器会弹出请求，选允许。说明里写得很清楚：授权之后，App 和内置 CLI 的所有 root 命令都静默执行，不再逐条确认。
3. 状态变成已授权、已连接，桥接端口显示具体端口号，说明通道已经起来。
4. 回到本机引擎页，把引擎停止再启动一次。地址和口令是在引擎启动时传进去的，不重启就还是旧的。重启后正在生成的回复会中断。

之后在对话里直接说要做的事即可，例如「用 root 看一下这台手机的 GPU 频率」。

手机上有 `su` 时，不打扰模式的「保持」缺省就是 root：开机或 App 重启后会自动重连，不必每次手动准备。没有 `su` 的手机不会被默认值拉去弹授权；你手动改过通道后，保持就以你的选择为准。

## 状态

页面上半部分是状态：

- 授权、连接：分别显示已授权或未授权、已连接或未连接。未授权时不会建立 root 连接。
- 当前 uid：root 同伴进程的身份，0 才是真正的 root。
- 桥接端口：显示未开启表示通道还没起来，通常是没授权或 App 进程刚被系统回收。
- 上次错误：显示最近一次失败的错误码，例如超时、已有命令在执行、root 不可用。括号里的英文码是协议里的原因码，发给开发者排查时有用。
- 刷新：重新读取一次状态。

## 自检

点自检，会以 root 执行一次 `id -u`：通过时显示 uid=0；显示其它 uid 说明 root 管理器给的不是 root 身份；显示失败会带上原因。自检不申请新的权限，只检查当前通道。

## 内置 CLI

rootfs 里预装了 `dsh-root`，Agent 和你都可以直接用。常用写法：

```sh
dsh-root id -u
dsh-root 'getprop ro.product.model'
dsh-root -c /data/local/tmp ls -l
dsh-root -t 10000 'dumpsys gpu | head -n 40'
dsh-root --status
```

需要跑得久的命令用后台模式，命令立即返回进程号和日志路径：

```sh
dsh-root -d 'logcat -c; logcat > /data/local/tmp/agent.log'
dsh-root --poll <进程号>
dsh-root --kill <进程号>
```

限制：

- 前台单条命令最多 25 秒（默认 20 秒），超时会结束并报超时。更长的活请用后台模式。
- 单次输出（标准输出、标准错误各自）最多 256 KiB，超出会截断并提示。
- 后台任务最多同时 8 个；前台同时最多 2 条，再多会提示忙。
- 每次只执行一条非交互的 Android `sh` 命令，没有终端、不能输入密码，不继承 Ubuntu 的路径、工作目录和环境变量。
- 只做 root 才能做的事，普通 Linux 命令留在 PRoot 里跑。

## 审计日志

每一条命令都会记录，包括失败的：时间、来源（App 或内置 CLI）、退出码、耗时、命令本身。页面里显示最近 50 条。

- 导出：复制一份交给系统分享，原日志不动。
- 清空：同时清掉当前日志和上一代备份，不可恢复；之后执行的命令仍会继续记录。
- 写日志失败不影响命令结果。

对话里执行的命令会连同命令原文一起记录，所以不要把密码、验证码、密钥写进 root 命令。

## 撤销与注意

危险区里的撤销授权会立即断开 root 连接：正在执行的前台命令会失败，之后需要重新授权才能再用。

- 它不是沙箱：授权等价于把 root shell 交给 DSH 和它加载的插件。只在信任的插件和对话里使用。
- 用不到时撤销授权；日常任务能用 PRoot 完成就不要开。
- 后台任务由 App 的 root 同伴进程持有，App 被系统回收后可能随之结束；用完记得用 `--kill` 收尾。
- 输出可能包含设备的敏感信息，发送给模型前先确认内容可以外发。
